 EDILGESTION — RIEPILOGO COMPLETO DEL PROGETTO
 Data: 26/08/2026
 Piattaforma: Base44 (React + Tailwind CSS + Vite)
================================================================================

MISSION
-------
EdilGestion è una piattaforma gestionale versatile e intuitiva progettata per
ottimizzare i processi aziendali, con strumenti dedicati alla pianificazione,
alla gestione delle risorse e al coordinamento operativo, ideale per il
settore edile e non solo.

OBIETTIVO A LUNGO TERMINE
-------------------------
Migrare la suite di plugin WordPress di EdilGestion verso un'app web nativa
in Base44, allineandola alle specifiche tecniche del gestionale MSS, includendo:
- Gestione cantieri avanzata
- Documentazione multimediale
- Collaborazione interna
- Gestione pagamenti
- Sistema di agenda
- Esportazione dati
- Gestione account
- Sistema di backup multi-cloud
- Dashboard dinamica
- Funzionalità di input vocale evoluto


================================================================================
 DECISIONI ARCHITETTURALI
================================================================================

- Architettura React su Base44 per sostituire i plugin WordPress esistenti
- Mantenimento dell'identità stilistica originale (#0d0d1a, tema dark)
- Autenticazione tramite Google nativamente
- Sostituzione di admin-ajax.php con entità e API integrate di Base44
- Layout responsive con sidebar fissa (desktop) e tab bar (mobile)
- Sistema di ruoli utenti: admin, mssg_admin, mssg_capo, mssg_operaio, mssg_cliente
- Agenda con griglia settimanale cliccabile (desktop/tablet) e vista dettaglio
  giornaliera (mobile)
- Blocchi di disponibilità con opzione manuale per fissare eventi nell'agenda
- Componenti Accordion per le sezioni nelle Impostazioni
- Sistema di "Promemoria veloci" integrato in Agenda e Dashboard
- Override dei blocchi giornata in Agenda da parte degli amministratori
- DashboardConfig per gestire layout personalizzabile di widget e azioni rapide
- Web Speech API per dettatura testo e comandi vocali tramite AI
- Promemoria integrati nella visualizzazione settimanale dell'agenda (colore ambra)
- Centralizzazione elaborazione comandi vocali in funzione backend
  (interpretaComandoVocale)
- Normalizzazione fuzzy dei nomi per matching entità correlate
- Pulsante "Comando Vocale" persistente in overlay (Sparkles)
- Interazione vocale bi-direzionale con notifiche cliccabili
- Supporto comandi vocali per creazione, aggiornamento ed eliminazione entità
- Dialog di dettaglio separati per visualizzazione (non modifica) di
  appuntamenti e promemoria in Agenda


================================================================================
 PREFERENZE DI DESIGN E UX
================================================================================

- Pulsanti di modifica ed elimina sempre visibili sulle card
- Dati di fatturazione (PIVA, CF, indirizzo) e flag "Azienda" nelle anagrafiche
- Menu responsabile nel CantiereSquadra mostra solo collaboratori con
  qualifica "capo_cantiere"
- Inserimento collaboratore gestisce automaticamente invio mail di benvenuto
  e reset password
- Barre delle fasi colorate per stato: vuota (da fare), gialla (in corso),
  rossa (bloccata), verde (completata)
- Percentuale prevista obbligatoria per creare nuove fasi lavorazione
- Widget dashboard: notifiche, ultime chat, pagamenti del mese, appuntamenti
  di domani, pienezza settimana
- Appuntamenti distinguono "lavorativo" e "personale" con colorazione diversa
- Gestione disponibilità supporta blocco di intervalli temporali multi-data
- Dati dinamici nelle email escapati per prevenire HTML/URL injection
- Agenda mostra settimana in alto con navigazione, giorni cliccabili
- Giorno in corso preselezionato all'apertura dell'agenda
- Filtri categoria/stato non causano salto pagina verso l'alto
- Pagine con molte opzioni usano Accordion
- Widget dashboard con liste cliccabili rimandano alle entità di riferimento
- Ogni dettaglio appuntamento ha link rapido verso vista principale Agenda
- Giorni bloccati nel widget settimana indicano 100% riempimento (rosso)
- Barra azioni rapide in dashboard con spaziatura definita rispetto ai widget
- Azioni rapide configurabili (aggiunta/rimozione/spostamento)
- Notifiche (Toast) non sovrappongono il pulsante AI (posizione modificata)

================================================================================
 FUNZIONI BACKEND
================================================================================

1. interpretaComandoVocale (entry.ts)
   - Elabora comandi vocali naturali tramite LLM
   - Supporta creazione, aggiornamento ed eliminazione di:
     Cliente, Collaboratore, Cantiere, Lavorazione, Appuntamento, Promemoria
   - Normalizzazione fuzzy dei nomi per matching entità
   - Utility: Levenshtein distance, stripping articoli/preposizioni italiani
   - Validazione input tramite schema JSON
   - Cross-entity linking e data validation

2. inviaNotificaAppuntamento (entry.ts)
   - Invia notifica email al cliente per appuntamenti
   - Fallback con notifica in-app

3. inviaNotificaPagamento (entry.ts)
   - Invia notifica email al cliente per pagamenti/scadenze

4. notificaEmailFallback (entry.ts)
   - Sistema fallback notifiche via email

5. backupSuCloud (entry.ts)
   - Esecuzione backup su provider cloud esterno
   - Supporta Google Drive, OneDrive, Dropbox, Amazon S3

MODULI CONDIVISI:
- base44/shared/firmaEmail.ts — Logica firma email condivisa tra funzioni

================================================================================
 SICUREZZA (RLS — Row Level Security)
================================================================================

Ogni entità ha RLS configurata:
- admin: accesso completo a tutto
- mssg_admin: gestione completa (eccetto eliminazione su alcune entità)
- mssg_capo: lettura completa + creazione/modifica su cantieri, lavorazioni,
  pagamenti, appuntamenti, presenze
- mssg_operaio: lettura + creazione presenze e appuntamenti
- mssg_cliente: lettura solo propri dati (cantieri, pagamenti, documenti,
  aggiornamenti, chat visibili, appuntamenti propri)
- Promemoria e DashboardConfig: accesso limitato al proprietario
